# Reporting a security vulnerability

For a suspected vulnerability in Roxy-WI, email
[hello@roxy-wi.org](mailto:hello@roxy-wi.org) with the subject
**Roxy-WI security report**. Do not disclose an unpatched vulnerability in a public
issue or discussion.

Include the affected version, installation method, required access, reproduction
steps, expected impact and any minimal proof of concept. Use synthetic data and
remove passwords, private keys, session tokens and customer information.

This repository's documentation covers **9.1 and later**. Include the exact
version or commit in your report so maintainers can identify the affected code.

For ordinary bugs and installation questions, see [Support](SUPPORT.md).
