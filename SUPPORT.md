# Get help with Roxy-WI

For **Roxy-WI 9.1 and later**, begin with the [documentation](docs/README.md),
[quick start](docs/quick-start.md) and [operations guide](docs/operations.md).

| Need | Channel |
| --- | --- |
| Reproducible bug | [GitHub issue forms](https://github.com/roxy-wi/roxy-wi/issues/new/choose) |
| Usage question or idea | [GitHub Discussions](https://github.com/orgs/roxy-wi/discussions) |
| Subscription or commercial support | [Plans](https://roxy-wi.org/pricing) or [hello@roxy-wi.org](mailto:hello@roxy-wi.org) |
| Security vulnerability | [Private reporting instructions](SECURITY.md) |
| Project announcements | [Telegram channel](https://t.me/roxy_wi_channel) |

When asking for help, include the version or commit, package/Compose/Helm
installation method, relevant service versions, steps to reproduce and sanitized
error output. For queued jobs, include the operation ID and role health results.
Never post complete environment files, database dumps, private keys or credentials.

Community discussions and issues do not carry a response-time commitment.
Commercial support terms are defined by your subscription.
