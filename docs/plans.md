# Plans and feature availability

> Applies to **Roxy-WI 9.1 and later**.

Start with the [live demo](https://demo.roxy-wi.org) to explore the interface.
Installing Roxy-WI does not activate a paid subscription. The
[plans page](https://roxy-wi.org/pricing) lists prices, included services and
support options; check it before choosing a plan.

| What you need | Where to start |
| --- | --- |
| Manage proxy configurations and services yourself | Manual: the self-hosted application under the [Apache 2.0 license](../LICENSE). |
| Add monitoring, metrics and automated service checks | Home: see the included monitoring services and agent limits on the plans page. |
| Manage HA clusters, use integrations and get technical support | Enterprise: see the available API, backup and support features. |
| Review, approve and roll out changes with Change Center | Premium; also required for Git backups and SMON status pages. |

For OIDC, the application requires an active Company plan or higher. Subscription
identifiers shown by the API can differ from the names on the plans page; confirm
OIDC availability with [support](../SUPPORT.md) when selecting a subscription.

Subscription features still enforce the user's role, group and service permissions.
A subscription does not grant access to another group's servers or credentials.

To evaluate Change Center, use the [guided tour](change-center-tour.md) with an
active Premium subscription and test servers you control. For an installation
without a subscription, begin with the configuration editor and service views.
