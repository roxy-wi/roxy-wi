# Connection profile screenshots

The light and dark screenshots show the authenticated connection-profile editor
using a fresh local product-test database and synthetic credentials. Password
fields are empty after reloading a saved profile; only the configured flag is
visible. The connection check is substituted in the browser scenario, while
separate loopback integration tests exercise real TLS, mTLS and HTTPS receiver
authentication. These images document the UI, not completed Proxmox qualification.
